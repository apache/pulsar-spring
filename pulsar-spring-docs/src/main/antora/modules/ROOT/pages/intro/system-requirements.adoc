= System Requirements

include::../attributes/attributes-variables.adoc[]

Apache Pulsar support for Spring `{pulsar-spring-version}` requires the following:

- https://www.java.com[Java 17] or above
- {spring-framework-docs}[Spring Framework `{spring-framework-version}`] or above
- {apache-pulsar-cient-docs}/[Apache Pulsar Java Client `{pulsar-client-version}`] or above

The version compatibility matrix (including Spring Boot) can be found in the xref:appendix/version-compatibility.adoc[appendix].
