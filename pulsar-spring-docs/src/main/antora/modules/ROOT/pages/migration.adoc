[[migration]]
= Migration from Spring's Pulsar support
include::partial$attributes.adoc[]

Apache Pulsar support for Spring is derived from Spring for Apache Pulsar, also known as Spring Pulsar, from the Apache Pulsar starter and auto-configuration in Spring Boot, and from the Apache Pulsar binder in Spring Cloud Stream.
This page describes where the project came from and what you need to change when you move an application to it.

[[migration-background]]
== Background

The project is derived from these works, all licensed under the Apache License, Version 2.0:

* Spring for Apache Pulsar, also known as Spring Pulsar, in https://github.com/spring-projects/spring-pulsar[spring-projects/spring-pulsar]: the core library and test utilities
* The Apache Pulsar starter and auto-configuration in Spring Boot, in https://github.com/spring-projects/spring-boot[spring-projects/spring-boot]: the xref:spring-boot.adoc[Spring Boot auto-configuration] and starters
* The Apache Pulsar binder in Spring Cloud Stream, in https://github.com/spring-cloud/spring-cloud-stream[spring-cloud/spring-cloud-stream]: the xref:cloud-stream-binder.adoc[Spring Cloud Stream binder]

Those works remain the copyright of their original authors and contributors, as stated in the headers of the source files.

Further development happens under the Apache Pulsar project in the https://github.com/apache/pulsar-spring[apache/pulsar-spring] repository.

[[migration-updating]]
== Updating your application

The Maven coordinates and Java packages have changed:

[cols="1,1",options="header"]
|===
| Previous | New

| `org.springframework.pulsar:spring-pulsar`
| `org.apache.pulsar:pulsar-spring`

| `org.springframework.pulsar:spring-pulsar-bom`
| `org.apache.pulsar:pulsar-spring-bom`

| `org.springframework.pulsar:spring-pulsar-test`
| `org.apache.pulsar:pulsar-spring-test`

| `org.springframework.boot:spring-boot-pulsar`
| `org.apache.pulsar:pulsar-spring-boot-autoconfigure`

| `org.springframework.boot:spring-boot-starter-pulsar`
| `org.apache.pulsar:pulsar-spring-boot-starter`

| `org.springframework.boot:spring-boot-starter-pulsar-test`
| `org.apache.pulsar:pulsar-spring-boot-starter-test`

| `org.springframework.cloud:spring-cloud-stream-binder-pulsar`
| `org.apache.pulsar:pulsar-spring-cloud-stream-binder`

| Package `org.springframework.pulsar`
| Package `org.apache.pulsar.spring`

| Package `org.springframework.boot.pulsar`
| Package `org.apache.pulsar.spring.boot`

| Package `org.springframework.cloud.stream.binder.pulsar`
| Package `org.apache.pulsar.spring.cloud.stream.binder`
|===

Replace the previous dependencies rather than adding the new ones next to them, so that the previous auto-configuration and binder are not also on the classpath.

Spring Boot does not manage the version of these artifacts, so you need to declare it, either on each dependency or by importing `pulsar-spring-bom`.
Spring Boot applications must also always set the `pulsar.version` property, since Spring Boot manages an older version of Pulsar.
It's also recommended to set `netty.version` to the most recent 4.2.x release of Netty.
See xref:appendix/override-boot-dependencies.adoc[] for how to set them.

This project requires the Pulsar `5.0.x` client, and has changed from `pulsar-client-all` to the unshaded artifacts, as described in xref:intro/system-requirements.adoc#pulsar-client-dependencies[Pulsar client].
Exclude `pulsar-client-all` if another dependency brings it in, and don't use classes from `org.apache.pulsar.shade`.

The `+spring.pulsar.*+` and `+spring.cloud.stream.pulsar.*+` configuration properties have not changed.

== Updating your tests

Spring Boot's Pulsar tests create their containers with `TestImage.forContainer(PulsarContainer.class)`, but `TestImage` is internal to the Spring Boot build and is not published.
If you have tests derived from them, use `org.apache.pulsar.spring.test.support.PulsarTestImage` from `pulsar-spring-test` instead:

[cols="1,1",options="header"]
|===
| Previous | New

| `TestImage.forContainer(PulsarContainer.class)`
| `PulsarTestImage.createContainer()`

| `TestImage.PULSAR.toString()`
| `PulsarTestImage.getDefaultImage().asCanonicalNameString()`
|===

The container uses the same startup settings as `TestImage.PULSAR` and defaults to the image of the Pulsar version that this project is built with.
You can select another version with `PulsarTestImage.createContainer(String)` or another image with `PulsarTestImage.createContainer(DockerImageName)`.
See xref:testing-applications.adoc#pulsar-test-image[PulsarTestImage] for more information.
