[[version-compatibility]]
= Pulsar Clients and Spring Boot Compatibility

include::partial$attributes.adoc[]

The following is the compatibility matrix:
|===
| Apache Pulsar support for Spring | Pulsar Client | Spring Boot | Java

| 3.0.x
| 5.0.x
| 4.1.x
| 17+

|===

The Pulsar `5.0.x` client is fully compatible with older Pulsar broker versions.

Spring Boot applications must xref:appendix/override-boot-dependencies.adoc[set the Pulsar version].

For earlier versions, see the https://docs.spring.io/spring-pulsar/reference/appendix/version-compatibility.html[Spring for Apache Pulsar compatibility matrix].
